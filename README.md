# CampusMart — Online Marketplace Platform

A responsive, multi-file web application built using **HTML5**, **CSS3**, and **Vanilla JavaScript** covering every topic in the Web Technologies syllabus and all functional requirements of the Online Marketplace project rubric.

## Folder Structure

```text
CampusMart-Marketplace/
├── index.html   # Semantic HTML5 layout, forms, tables, SVG, audio, video, iframe & modals
├── styles.css   # CSS3 variables, Flexbox, CSS Grid, pseudo-classes, attribute selectors, animations & media queries
├── app.js       # JavaScript data structures, search/filter/sort, cart/checkout, reviews, auth & Admin CRUD
└── README.md    # Setup instructions and syllabus mapping
```

## How to Run

1. Extract `CampusMart-Marketplace.zip`.
2. Open the `CampusMart-Marketplace` folder in **VS Code**.
3. Right-click `index.html` and choose **Open with Live Server** (or open `index.html` directly in any browser).
4. Click **Login / Register** in the top navigation bar and choose either **Customer** or **Admin** role to test checkout, reviews, and full Admin CRUD operations.

## Syllabus & Project Rubric Mapping

| Syllabus Unit | Concepts Applied in Project |
| :--- | :--- |
| **HTML Fundamentals** | HTML5 boilerplate, SEO meta tags, headings, lists (`<ol>`, `<ul>`), hyperlinks, inline `<svg>` logo, `<audio>`, `<video>`, and `<iframe>` map embed. |
| **Semantic HTML & Forms** | `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, accessible labels, `<fieldset>`/`<legend>`, `<input>` types, validation attributes, and structured `<table>` views. |
| **Cascading Style Sheets** | External stylesheet, `:root` CSS variables, box model, Flexbox navbar, CSS Grid catalogue (`auto-fill`), `:hover` & `:nth-child()` pseudo-classes, `[type="..."]` attribute selectors, `@keyframes` animations, transitions, and `@media` responsive breakpoints. |
| **JavaScript Fundamentals** | `const`/`let` scope, primitives (strings, numbers, booleans), operators, string/array methods (`filter`, `sort`, `map`, `reduce`, `find`), object manipulation, form validation, and `localStorage` persistence. |
